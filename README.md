# 🌍 Beyond Borders – Travel Website  

## 📌 Project Overview  
**Beyond Borders** is a simple travel website built using **HTML5**.  
It serves as a beginner-friendly project to demonstrate essential HTML concepts such as headings, paragraphs, text formatting, lists, tables, images, videos, links, and forms.  

The website introduces the travel agency "Beyond Borders," showcasing destinations, travel packages, essential travel requirements, and a gallery for inspiration.  

---

## ✨ Features  
- **Agency Introduction** – A short description of who we are.  
- **Famous Destinations** – An unordered list of top travel places.  
- **Essential Things** – An ordered list of must-have items while traveling.  
- **Travel Terms** – A definition list explaining key travel terms (Visa, Itinerary, Backpacking).  
- **Packages** – A table of travel packages with price ranges and durations.  
- **Gallery** – Travel photos and a video to showcase destinations.  
- **Registration Form Link** – A hyperlink to register (opens a form page).  
- **Explore More Section** – Contact, email, reviews, and address links.  
- **Footer** – Copyright information.

---

## 🛠️ Tech Stack

- **Images & Video** – for gallery content.

## 🚀 Getting Started  
1. Clone or download this repository.  
2. Place all images (`.jpeg`, `.jpg`) and video (`.mp4`) in the same directory as `index.html`.  
3. Open `index.html` in any modern web browser.
